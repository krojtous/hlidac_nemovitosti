Přístupový token

Bez tokenu se ukládá ručně (viz níže). S ním stačí tlačítko výš. Vyrob si ho na github.com/settings/personal-access-tokens: Repository access → Only select repositories → tenhle repozitář, Permissions → Repository permissions → Contents: Read and write. Nic jiného token neumí.

Token zůstává jen v tomhle prohlížeči (localStorage) a odesílá se pouze na api.github.com. Na cizím ani sdíleném zařízení ho nezadávej.
